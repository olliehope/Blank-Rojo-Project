## Getting Started
Install the project tools and packages:

```bash
npm install
wally install
```

Generate the Rojo project tree after adding or moving source files:

```bash
npm run build:rojo
```

Source folders are split by context:

- `src/client` maps to `StarterPlayerScripts`
- `src/shared` maps to `ReplicatedStorage.Shared`
- `src/server` maps to `ServerScriptService`
- service files named `Server.luau` under `src/shared/services` are remapped to `ServerScriptService.Services`

If PowerShell blocks `npm`, use `npm.cmd` instead:

```bash
npm.cmd run build:rojo
```

To build the place from scratch, use:

```bash
npm run build
```

Next, open `murdermystery.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
